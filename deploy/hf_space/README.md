# EgressTwin (static demo)

This Space replays one recorded real run of EgressTwin, an agent that turns
a floor-plan image into an evacuation digital twin. The plan is
`spike_plan_hand.png`, simulated with 200 people. The agent is Muse Spark
1.3 through the Meta Model API. The page shows the perceived layout, the
baseline simulation and the agent trace, with each turn's response id,
tokens and cost. It also shows the verifier's claim-by-claim checks and
the benchmark figures.

This is a static export of the app's demo-only mode, generated by
`scripts/deploy_space.py`. It has no server and no API key, and it makes
no API calls. Uploading plans, simulating and optimizing need a local
install from the source repository:
https://github.com/ManuelSanabria2/Egresstwin

Decision support, not a safety certification.
